I read both zips. Here is what each one is and where it fits.
What the folders do
LocalAIStudio is a ready-made chat website: a FastAPI backend, a dark chat page, Chroma for search and llama.cpp for the model.
app/main.py is the server that receives questions and calls the model.
app/static/index.html is the chat page.
config/settings.json holds the app name, system prompt and settings.
knowledge/raw/ is where documents go.
scripts/ingest.py reads documents and indexes them.
nanoGPT is a small educational GPT (Transformer) that you can read and train.
model.py is the Transformer itself (self-attention and layers).
train.py trains it, sample.py generates text from it, and config/ holds its settings.
data/ has dataset preparation scripts (Shakespeare, OpenWebText).
The .ipynb notebooks explain model size and scaling.
How they fit your project
Don't build your chatbot on LocalAIStudio. Your own pipeline is already better matched to the assignment. LocalAIStudio:
splits text by characters, so it keeps no page numbers and no book_id/chunk_id (the assignment requires them)
needs a separate llama.cpp download plus a GGUF model
has a bug in main.py: Chroma's query parameter is n_results, not n, so chat would crash
You can borrow its look later, but your current setup is the right core.
Use nanoGPT only for the "Transformer fundamentals" deliverable. Read model.py to explain self-attention and the architecture. Training a useful chatbot from scratch on 4 GB RAM isn't realistic, and the assignment doesn't require it. Optionally run its tiny CPU demo (see Step 6).

Step 4: Evaluation script. Create evaluate.py. It measures Recall@5, abstention and speed without loading the answering model:
import json, time, faiss, numpy as np
from sentence_transformers import SentenceTransformer

MIN_SCORE = 0.30
chunks = json.load(open("chunks.json", encoding="utf-8"))
index = faiss.read_index("books.index")
emb = SentenceTransformer("all-MiniLM-L6-v2")
qs = json.load(open("evaluation_questions.json", encoding="utf-8"))

hits = tot_ans = abst_ok = tot_no = 0
times = []
for item in qs:
    t = time.time()
    v = emb.encode([item["question"]], normalize_embeddings=True)
    scores, ids = index.search(np.array(v, dtype="float32"), 5)
    times.append(time.time() - t)
    top = [chunks[i] for i in ids[0]]
    if item["answerable"]:
        tot_ans += 1
        if any(c["book_id"] == item["book_id"] and abs(c["page"] - item["page"]) <= 1 for c in top):
            hits += 1
    else:
        tot_no += 1
        if scores[0][0] < MIN_SCORE:
            abst_ok += 1

report = {
    "recall_at_5": hits / max(tot_ans, 1),
    "abstention_rate": abst_ok / max(tot_no, 1),
    "avg_retrieval_seconds": sum(times) / len(times),
    "questions": len(qs),
}
json.dump(report, open("report.json", "w"), indent=2)
print(report)
Run it with py -3.11 evaluate.py. Answer correctness and citation correctness still need to be checked by hand: ask the chatbot each question and compare against the book page.
Step 5: Tests. Create test_project.py:
import json, faiss

chunks = json.load(open("chunks.json", encoding="utf-8"))

def test_required_fields():
    need = {"group_id", "subject", "book_id", "title", "page", "chunk_id", "text"}
    assert all(need <= set(c) for c in chunks)

def test_chunk_ids_unique():
    ids = [c["chunk_id"] for c in chunks]
    assert len(ids) == len(set(ids))

def test_index_matches_chunks():
    assert faiss.read_index("books.index").ntotal == len(chunks)

def test_fifteen_books():
    assert len({c["book_id"] for c in chunks}) >= 15
Run it with py -3.11 -m pytest.
